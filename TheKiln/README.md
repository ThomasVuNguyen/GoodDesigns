# The Kiln

A static clone of [thekiln.com](https://thekiln.com/) for the GoodDesigns gallery.

## Reference

- **URL:** https://thekiln.com/
- **Captured:** October 2026
- **Built with:** Framer (original), single-file HTML + inline CSS (clone)

## Description

The Kiln is a GTM (Go-To-Market) engineering services company (acquired by 2X). The site showcases their services including Sales & GTM Engineering, Marketing & Growth, and RevOps, along with case studies, testimonials, and a CTA section.

## Run

```bash
cd dist
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
